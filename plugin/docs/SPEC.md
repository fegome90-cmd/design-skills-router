# Design Skills Router · supervised pilot

Use the supplied v0.4 canonical decision tree unchanged, not a new linear workflow. Package a single discoverable skill, its references and a standard-library Python helper. Scope: human-supervised web UI; retain blocked routes and incomplete inventory dispositions. Preserve the user's project sources, stack and authority. No cloud service, external database, repository mutation or autonomous tool enforcement.

Each node packet includes all alternatives, applicable skill IDs and criterion sources. Record decision summaries (not private reasoning), alternatives, retrieved-source receipts and evidence. A proposal does not advance until a separate user confirmation referring to its exact hash exists. All branches of an ALL node stay active. Node approval never approves descendants. Structure approval and project-answer approval are separate. Required external sources are retrieved through available supported tools at their pinned revisions, cached per project, never silently replaced. Missing sources block proposal submission. A source receipt establishes byte receipt, not comprehension.

Persist portable per-project state outside the installed plugin. Guard updates by revision; atomic replacement. Preserve history and invalidate approvals conservatively after upstream changes. Unknown routes never fall back to web. All 82 inventory entries remain visible and require explicit dispositions before a production-readiness report. This helper cannot authenticate a user-message file or stop tools used outside it; human approval remains a supervised protocol.

Deliver one actual private account plugin and its editable ZIP after local tests. Do not label creation as fresh-chat activation or agent-obedience validation.
