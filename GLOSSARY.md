# Design Skills Router

Repositorio que reúne un router de skills de diseño, la pizarra que permite inspeccionar sus decisiones y las fuentes fijadas de las skills referenciadas.

## Language

**Baseline de plataforma**:
Conjunto de ajustes de GitHub y archivos de política que el repositorio adopta como línea base.
_Avoid_: subconjunto seguro, mejores prácticas

**Thread de revisión**:
Comentario anclado a una línea del diff de un pull request, con estado resuelto o pendiente; es el único tipo de comentario que bloquea el merge cuando la resolución de conversaciones está activa.
_Avoid_: comentario, conversación
